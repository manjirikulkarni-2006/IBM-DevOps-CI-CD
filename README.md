[![CI Build](https://github.com/manjirikulkarni-2006/IBM-DevOps-CI-CD/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/manjirikulkarni-2006/IBM-DevOps-CI-CD/actions/workflows/ci-build.yaml)

## Project Overview

This project demonstrates the implementation of a RESTful Account Microservice and a Continuous Integration and Continuous Delivery (CI/CD) workflow.

## Objectives

- Develop REST API endpoints to create, read, list, update, and delete accounts.
- Configure automated linting and unit testing.
- Implement security headers and Cross-Origin Resource Sharing (CORS).
- Containerize the application using Docker.
- Deploy the application to Kubernetes.
- Automate deployment using a CI/CD pipeline.

## Technologies

- Python and Flask
- REST APIs and SQLAlchemy
- Nose, Coverage, Flake8, and Pylint
- GitHub Actions
- Docker and Kubernetes
- Tekton Pipelines
